## 1. 测试范围

### 1.1 在范围内

- `useConnectAccount` — 链接新设备扫码流程
- `useConnectTerminal` — 连接 Terminal 扫码流程
- `QRScannerScreen` 组件行为（权限、打开、关闭、扫码识别）
- `useCheckCameraPermissions` 权限请求
- 负向路径：非 happy URL、错误前缀、权限拒绝、重复触发

### 1.2 不在范围内

- `processAuthUrl` 的网络层逻辑（已有独立测试覆盖）
- iOS Push Notification 功能（无关）
- Web 平台（无相机扫码功能）

### 1.3 测试环境要求

> ⚠️ **必须使用 EAS dev build 或 production build**。  
> `react-native-vision-camera` 是 native module，Expo Go 不支持，会直接 crash。Expo Go 的 crash **不代表实现有误**，不得以此作为 bug 记录。
